Hi i have a private event with guests.

The app would need to have

1.  An admin which will allow to

    1.  Login (email / psw)

    2.  Create an event. Each event would have these settings

        1.  Language preference: Hebrew or English

        2.  web page setting which will include

            1.  an image

            2.  event full address link to navigate to the location (i.e. will open waze or google map)

            3.  greeting

        3.  list of guests

            1.  first name

            2.  last name

            3.  unique mobile number

            4.  predicted guests

            5.  family e.g. mother / father…

    3.  send the event link to event guest(s)

        1.  link will open event invite page in context of the guest

        2.  multi selection of guests can be made

    4.  view guest answers to understand how many guests will come

    5.  View list of created events which the logged in user created

    6.  Set the event as active / inactive (inactive event means guest wont be able to view event page)

2.  end user

    1.  will be able to get an event link via e.g. whatapp

    2.  pressing the link

        1.  will open the event web page

            1.  could be opened only via a dedicated link sent to the guest

            2.  In case event is not active a default message will be displayed

        2.  web page which has been opened in context of a guest will include

            1.  event image

            2.  event full address + link to navigate to the location (i.e. will open waze or google map)

            3.  greeting e.g. hello \[first name\] \[last name\] we are happy to invite you to our party ….

            4.  Allow to set how many guests will arrive (+/-). Min 0 max 10

        3.  submit button
